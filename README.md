# lau-ergodic-gradient

**Kimi's Theorem 3: gradient descent as the time-reversal of ergodic diffusion (Fokker-Planck). Bakry-Émery curvature, spectral gap, log-Sobolev inequalities, Wasserstein contraction, JKO scheme, and Fisher-Ricci curvature for optimization.**

## What This Does

This crate implements the theorem that **gradient descent on a loss landscape is the time-reversal of ergodic diffusion generated by the Fokker-Planck operator**. It provides:

- **Fokker-Planck simulation** — evolve probability densities under `∂_t ρ = ∇·(ρ∇Φ) + Δρ`
- **Time-reversed gradient flow** — gradient descent as reversed Fokker-Planck
- **Bakry-Émery CD(K,∞) verification** — curvature-dimension conditions for convergence
- **Spectral gap estimation** — `λ₁ ≥ K` via Otto-Villani theorem
- **Log-Sobolev inequality verification** — entropy decay at rate `e^{-2Kt}`
- **Wasserstein-2 contraction** — `W₂(S_t ρ, S_t σ) ≤ e^{-Kt} W₂(ρ, σ)`
- **JKO scheme** — variational formulation `argmin { ½τ W₂² + Ent_μ }`
- **Parameter manifold optimization** — natural gradient descent on neural network loss landscapes
- **Fisher-Ricci curvature** — information-geometric Ricci curvature from the Fisher metric
- **PLATO agent belief updates** — convergence-guaranteed belief evolution

Everything is discretized on finite grids with central finite differences for spatial derivatives and Euler stepping for time evolution.

## Key Idea

The central correspondence (Kimi's Theorem 3):

```
Gradient descent  ≡  Time-reversed Fokker-Planck flow
```

| Optimization Concept | Ergodic Theory Counterpart |
|---|---|
| Loss landscape `L(θ)` | Potential `Φ(x)` |
| Gradient descent `θ ← θ - η∇L` | Time-reversed FP: `∂_t ρ = -∇·(ρ∇Φ) + DΔρ` |
| SGD noise | Diffusion coefficient `D` |
| Convergence to minimum | Convergence to Gibbs measure `μ ∝ e^{-Φ/D}` |
| Learning rate | Time step `dt` |
| Curvature of loss landscape | Bakry-Émery curvature `K` (min Hess eigenvalue) |
| Convergence rate | Spectral gap `λ₁ ≥ K` |
| Natural gradient | Riemannian gradient with Fisher metric |
| Loss landscape curvature | Ricci curvature of Fisher information metric |

When the potential satisfies CD(K,∞) (Hessian ≥ K·I), we get:
- **Spectral gap**: `λ₁ ≥ K`
- **Entropy decay**: `Ent(S_t ρ | μ) ≤ e^{-2Kt} Ent(ρ | μ)`
- **Wasserstein contraction**: `W₂(S_t ρ, S_t σ) ≤ e^{-Kt} W₂(ρ, σ)`
- **Log-Sobolev**: `Ent_μ(f²) ≤ (2/K) ∫|∇f|² dμ`

## Quick Start

```rust
use lau_ergodic_gradient::*;

// --- Create a quadratic potential (strongly convex landscape) ---
let potential = Potential::quadratic(1, 21, 0.1, 5.0); // 1D, 21 grid points, K=5

// --- Fokker-Planck evolution ---
let fp = FokkerPlanck::new(potential.clone(), 0.5); // D=0.5
let initial_density = Density::gaussian(1, 21, 0.1, 2.0);
let evolved = fp.evolve(&initial_density, 0.1, 50);
let gibbs = fp.gibbs_measure(); // stationary distribution

// --- Bakry-Émery curvature ---
let be = BakryEmery::new(potential.clone());
println!("Optimal curvature K = {:.3}", be.optimal_curvature());
println!("CD(5,∞) holds: {}", be.check_cd(5.0));
println!("Spectral gap ≥ {:.3}", be.spectral_gap());
println!("Log-Sobolev constant = {:.3}", be.log_sobolev_constant());

// --- Gradient descent as time-reversed flow ---
let tr = TimeReversedGradientFlow::new(potential.clone(), 0.1);
let result = tr.gradient_descent(&initial_density, 0.5, 100);

// --- Wasserstein contraction ---
let wc = WassersteinContraction::new(5.0);
let bound = wc.contraction_bound(1.0, 1.0);
println!("W₂ after t=1: ≤ {:.3}", bound);

// --- JKO scheme ---
let jko = JKOScheme::new(potential.clone(), 0.5, 0.01);
let jko_result = jko.evolve(&initial_density, 10);

// --- Natural gradient on parameter manifold ---
let mut pm = ParameterManifold::new(DVector::from_vec(vec![1.0, -1.0, 0.5]), 0.01);
pm.set_gradient(DVector::from_vec(vec![2.0, -1.0, 0.3]));
pm.set_fisher(DMatrix::identity(3, 3) * 2.0);
let new_params = pm.natural_gradient_step();

// --- Fisher-Ricci curvature ---
let fr = FisherRicci::from_fisher(DMatrix::identity(3, 3) * 2.0);
println!("Scalar curvature: {:.3}", fr.scalar_curvature());
println!("Min Ricci: {:.3}", fr.min_ricci_curvature());

// --- PLATO convergence analysis ---
let plato = PlatoBeliefUpdate::new(5.0, 0.5, 1, 21, 0.1);
let report = plato.convergence_analysis(1.0);
println!("Spectral gap: {:.3}", report.spectral_gap);
println!("W₂ contraction: {:.3}", report.w2_contraction);
println!("Mixing time (W₂, ε=0.01): {:.3}", plato.mixing_time_w2(0.01, 1.0));
```

## How It Works

### 1. Fokker-Planck Dynamics

The Fokker-Planck equation describes how a probability density evolves under drift (downhill on the potential) and diffusion (random noise):

```
∂_t ρ = ∇·(ρ∇Φ) + D·Δρ
```

The stationary distribution is the Gibbs measure `μ(x) ∝ exp(-Φ(x)/D)`.

### 2. Time-Reversed Gradient Flow

Gradient descent `dx/dt = -∇Φ(x)` concentrates probability at the minimum. This is the time-reversal of the Fokker-Planck flow (which spreads probability toward the Gibbs measure). The reversed operator flips the drift sign:

```
∂_t ρ = -∇·(ρ∇Φ) + D·Δρ
```

### 3. Bakry-Émery Curvature

CD(K,∞) holds when `Hess(Φ) ≥ K·I` (the potential is K-strongly convex). This gives convergence guarantees:
- Spectral gap `λ₁ ≥ K`
- Log-Sobolev constant `C_LSI = 2/K`
- Entropy decays as `e^{-2Kt}`

### 4. Wasserstein Contraction

Under CD(K,∞), the semigroup `S_t` contracts in W₂ distance:
```
W₂(S_t ρ, S_t σ) ≤ e^{-Kt} W₂(ρ, σ)
```

### 5. JKO Scheme

The Fokker-Planck equation is the gradient flow of relative entropy in Wasserstein space. The JKO scheme discretizes this:
```
ρ^{n+1} = argmin_ρ { ½τ W₂²(ρ, ρⁿ) + Ent_μ(ρ) }
```

### 6. Fisher-Ricci Curvature

For an exponential family `p(x|θ) = h(x) exp(θ·T(x) - A(θ))`, the Fisher metric `g_{ij} = ∂²A/(∂θᵢ∂θⱼ)` defines a Riemannian structure. The Ricci curvature tensor measures the curvature of parameter space — positive Ricci curvature means optimization converges fast.

## The Math

### Fokker-Planck Equation

```
∂_t ρ(x,t) = ∇·(ρ(x,t) ∇Φ(x)) + D Δρ(x,t)

Stationary solution: μ(x) = Z⁻¹ exp(-Φ(x)/D)
```

### Bakry-Émery CD(K,∞)

```
CD(K,∞): Hess(Φ) ≥ K·I  (as symmetric matrices)

⇒ Spectral gap: λ₁ ≥ K  (Otto-Villani)
⇒ Log-Sobolev: Ent_μ(f²) ≤ (2/K) ∫|∇f|² dμ
⇒ Entropy decay: Ent(S_t ρ | μ) ≤ e^{-2Kt} Ent(ρ | μ)
⇒ W₂ contraction: W₂(S_t ρ, S_t σ) ≤ e^{-Kt} W₂(ρ, σ)
```

### Gradient Descent as Time Reversal

```
Forward FP:   ∂_t ρ = +∇·(ρ∇Φ) + DΔρ  → converges to Gibbs μ
Reversed FP:  ∂_t ρ = -∇·(ρ∇Φ) + DΔρ  → concentrates at minimum

gradient descent: dx/dt = -∇Φ(x)  ≡  reversed FP on delta distributions
```

### JKO Variational Scheme

```
ρ^{n+1} = argmin_ρ { (1/2τ) W₂²(ρ, ρⁿ) + Ent_μ(ρ) }

This is the minimizing movements scheme for the gradient flow
of entropy in the Wasserstein metric (P₂, W₂).
```

### Fisher Information Geometry

For exponential family `p(x|θ)`:
```
Fisher metric: g_{ij} = E[∂ᵢ ℓ · ∂ⱼ ℓ]  where ℓ = log p(x|θ)
                = ∂²A/(∂θᵢ ∂θⱼ)

Christoffel symbols: Γᵏ_{ij} = ½ g^{kl} (∂ᵢ g_{jl} + ∂ⱼ g_{il} - ∂ₗ g_{ij})
Ricci tensor: Ric_{ij} = ∂ₖ Γˡ_{ij} - ∂ⱼ Γˡ_{ik} + Γˡ_{ks} Γˢ_{ij} - Γˡ_{js} Γˢ_{ik}
Scalar curvature: R = g^{ij} Ric_{ij}

CD(K,∞) on parameter manifold: min eigenvalue of (g⁻¹ Ric) ≥ K
```

### Mixing Time Bounds

```
t_mix^W₂(ε) = (1/K) ln(W₂(ρ, μ)/ε)
t_mix^Ent(ε) = (1/2K) ln(Ent(ρ|μ)/ε)
```
